# للتبريد والتكييف — Riyadh Service Website

Static bilingual Arabic/English website for GitHub + Vercel.

- No admin section, CMS, dashboard, login, database or API.
- Home, services, service detail pages, work/photos, areas, about, contact and WhatsApp booking.
- Call + WhatsApp CTAs throughout.
- Mobile fixed action bar.
- FAQ accordion + image lightbox.
- LocalBusiness/HVACBusiness JSON-LD.
- robots.txt, sitemap.xml, manifest.webmanifest and vercel.json.
- Supplied assets are included in `assets/`.

## Before launch
Replace `https://example.com` in sitemap/canonical/JSON-LD with your final domain and confirm the final business details.

## Deploy
Upload the contents to GitHub, then in Vercel choose Add New → Project → import the GitHub repository. No build command or environment variables are required.

There is intentionally no `/admin` route or admin code.
